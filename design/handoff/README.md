# Calculadora de Batería: paquete para implementar la app (Flutter)

Empieza por **`PROMPT.md`**: es el prompt para pegar en Claude Code.

| Carpeta | Contenido |
|---|---|
| `PROMPT.md` | Prompt para Claude Code: orden de lectura, restricciones, arquitectura, fases y criterios de aceptación |
| `docs/SPEC.md` | Especificación funcional: fórmulas, validación, estados, persistencia y reporte (fuente de verdad) |
| `docs/DESIGN.md` | Especificación de diseño: estructura, pantallas, componentes con sus estados, comportamiento y accesibilidad |
| `docs/test-vectors.json` | 20 casos de prueba sacados del prototipo (entradas y textos esperados) |
| `docs/test-vectors-runtime.json` | 12 casos de prueba del modo Duración (SPEC §4.5), de una implementación de referencia |
| `design/tokens.json` | Colores en claro y oscuro con contrastes, escala de texto, espaciados, radios y alturas |
| `reference/screens/` | 39 capturas PNG del diseño (flujo en claro y oscuro, estados, peor caso, reporte, inglés, ícono y sistema) |
| `reference/prototype/` | Prototipo funcional: `prototype.html` (se abre sin internet) y `prototype-src.html` (legible, sin las fuentes incrustadas) |
| `assets/fonts/` | Atkinson Hyperlegible 400 y 700 en TTF, con su licencia OFL |
| `assets/icon/` | Ícono adaptativo: SVG de fondo, frente y monocromo, más PNG de 512 y 1024 |

El diseño original está en el lienzo de Claude («Calculadora de Batería · App Android») y el prototipo publicado en «Calculadora de Batería · Prototipo».
